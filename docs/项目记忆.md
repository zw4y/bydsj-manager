> 更新日期：2026-08-13

> 当前工作分支：`codex/cardkey-multi-account`

## 1. 项目概况

捕鱼大世界多账户管理软件是一套 Windows 桌面工具 + 云服务器授权体系：

- **用户端（app.py → BydsjApp.exe）**：卡密激活后管理多个游戏账号，自动登录查询背包/仓库、炮台、充值等信息，支持批量刷新、批量改密、仓库存取、动态代理。
- **管理端（admin_app.py → BydsjAdmin.exe）**：卡密生成/导出/停用/启用/解绑机器码，以及用户端版本发布。
- **卡密服务器（server/，FastAPI + SQLite，Docker 部署）**：卡密校验、机器绑定、管理员 JWT 鉴权、热更新版本分发。

现状：软件开发基本流程完成，服务器已上线，两个 exe 已封装，热更新已实现并验证；尚未进行干净电脑/朋友实测。

## 2. 技术栈与依赖

- Python 3.12 + PySide6（Qt6），原生控件 + QSS 浅色 Fluent 主题
- QThread + Signal 后台异步（登录、刷新、存取、改密、代理、更新检查）
- 服务器：FastAPI + Uvicorn + SQLite + python-multipart；Docker 部署
- 加密：cryptography（AES-GCM 本地账号库；PBKDF2 管理员密码）
- 网络：httpx、urllib；游戏协议为自研逆向客户端（bydsj_client / gaia_login）
- 打包：PyInstaller（单文件 exe）
- 代理：抖大代理动态 API（客户端直调 + 平台 IP 白名单）

## 3. 系统架构与数据流

```text
用户端 BydsjApp.exe ──HTTP──▶ 卡密服务器(云, 47.100.188.139:18432)
    │                                 │
    │ 游戏协议直连                    ├─ 卡密校验/机器绑定
    ▼                                 ├─ 版本清单/下载(热更新)
游戏服务器(i.bydsj3d.com 等)          └─ /data/cards.db + /data/releases

管理端 BydsjAdmin.exe ──HTTP──▶ 同上（管理员 JWT）
    ├─ 卡密管理
    └─ 发布用户端新版本
```

- 游戏流量（登录/背包/仓库/存取）由客户端直连游戏服务器，可选代理，**不经过卡密服务器**。
- 账号密码只存在用户本机 `%APPDATA%`，服务器不知道。
- 卡密服务器只负责授权与版本分发。

## 4. 功能清单

### 4.1 用户端

- 卡密激活：服务器校验 + 机器码绑定；服务器地址内置（`DEFAULT_SERVER_URL`），界面不显示
- 账号表（Excel 化）：
  - 10 列：序号、勾选、游戏账号、游戏密码、二级密码、手机号、设备码、游戏昵称、炮台、充值
  - 双击/F2 编辑即保存；右键菜单：登录、刷新、编辑账号信息、删除账号（清空数据）、删除此行、粘贴账号数据
  - Ctrl+V 批量粘贴（1-5 列）、任意位置插入/删除行、空白行保留、行序持久化（sort_order）
  - 空表时空白区域右击可“添加行 / 粘贴账号数据”
- 资源查询：自动登录 → 背包 + 仓库；16 项道具图标网格（4×4）；金币按“亿”显示；炮台、充值自动抓取
- 仓库存取：右键图标存入/取出，弹头上限 999，二级密码 + 信任设备短信验证
- 批量刷新：勾选多个账号自动排队、随机延迟（默认 5-15 秒）、代理轮换、可停止
- 批量改密：随机密码规则/指定密码；成功一个自动取消一个勾选
- 动态代理：启用开关 + API 链接 + 测试代理；每 IP 最多 8 账号；txt/json 兼容
- 日志：界面 + `%APPDATA%\BydsjManager\logs\operation.log` + 打开日志目录
- 热更新：启动自动检查 + “检查更新”按钮；下载进度、SHA-256 校验、updater 替换重启
- 浅色 Fluent 主题、蓝色勾选框
- 修复：windowed exe 中 `sys.stderr` 为 None 导致登录失败时报 “NoneType has no attribute write”；`_debug_response` 已加空值保护，updater 打印同样加固（2026-08-13）

### 4.2 管理端

- 管理员登录（JWT）
- 卡密列表、批量生成（一月卡/季卡/半年卡/年卡）、CSV 导出、停用/启用、解绑机器码
- 发布用户端新版本（版本号、说明、上传 exe）
- 服务器地址内置（`DEFAULT_SERVER_URL`），界面不显示

### 4.3 服务器

- `POST /api/admin/login`：管理员登录，返回 JWT
- `GET /api/admin/keys` / `POST /api/admin/keys/generate` / `GET /api/admin/keys/export`
- `PATCH /api/admin/keys/{id}/status` / `POST /api/admin/keys/{id}/unbind`
- `POST /api/admin/release`：管理员上传用户端新版本
- `POST /api/client/activate` / `POST /api/client/validate`：卡密激活/校验
- `GET /api/client/version` + `/releases/`：热更新版本清单与下载

## 6. 部署现状（服务器）

- 阿里云 ECS（国内），Ubuntu 22.04，2C2G，Docker 29.7.2
- 公网地址：`http://47.100.188.139:18432`（非标准端口）
- 容器：`card-server`（restart always），镜像 `card-server:latest`，数据卷 `card-data:/data`
- 服务器代码版本：2026-08-13 已升级重建（卡型 9 种、续费、删除、北京时间、心跳 validate 全部生效）
- 安全组：只放行 22 和 18432；80/443 关闭；纯 IP + 非标准端口方案（未备案，朋友自用）
- 管理员凭据保存在 `%TEMP%\bydsj_deploy_admin_credentials.txt`（临时目录，建议尽快转存）
- 管理员账号：`admin`；JWT 密钥仅在容器环境变量中

### 运维手册

- 管理员密码重置 / 忘记密码：备份 → 删除 `admin_users` 中 admin → 用新 `CARD_ADMIN_PASSWORD` 重建容器 → 自动重建 admin；卡密数据不受影响
- `JWT_SECRET`：签发/验证管理端令牌；泄露可伪造管理端；更换后旧令牌全部失效
- 备份：
  ```bash
  docker exec card-server tar czf /tmp/cards-backup.tar.gz /data
  docker cp card-server:/tmp/cards-backup.tar.gz /root/cards-backup.tar.gz
  ```
- 常用命令：`docker ps`、`docker logs --tail 50 card-server`、`docker restart card-server`
- 重要：只删 `admin_users` 不会丢卡密；绝不能删 `cards.db` 或数据卷；`cards.db` 含卡密明文，禁止外传

## 7. 打包与热更新

- 产物：`dist/BydsjApp.exe`（Nuitka 原生编译，约 40.6MB，自定义图标）、`dist/BydsjAdmin.exe`（PyInstaller，约 51MB）、`dist/updater.exe`（PyInstaller，内嵌）
- 打包：`packaging/build.py`（先打 updater，再打用户端，最后管理端）；严格排除逆向/开发资产
- 打包命令：`python packaging/build.py --user-app nuitka`（用户端默认 Nuitka；需设置 `NUITKA_CACHE_DIR` 到可写目录，已加 `--experimental=force-dependencies-pefile` 解决中文路径依赖检测问题）
- 版本：`app.py` 中 `APP_VERSION = "1.0.1"`（已发布）
- 发布流程：管理端“发布版本”→ 填版本号/说明/选 exe → 服务器存 `/data/releases` 并更新 `version.json` → 用户端自动检查下载更新
- 客户端更新：启动自动检查 + 手动按钮；进度下载、SHA-256 校验、updater 替换、失败保留旧版
- 更新加速待选（暂缓）：Gitee 公开仓库外链；长期方案香港 COS + CDN（免备案）

## 8. 数据存储与安全

- 用户端账号库：`%APPDATA%\BydsjManager\<卡密哈希>\accounts.db`（SQLite，AES-GCM 加密密码）
- 用户端配置/日志/设备码/更新包：`%APPDATA%\BydsjManager\` 下 JSON/文本/文件
- 服务器：`/data/cards.db`（SQLite）+ `/data/releases/`（文件）
- 管理员密码：PBKDF2 哈希；JWT 仅进程内存
- 卡密：服务器存哈希用于校验，同时按需求存明文供管理端展示；本地不存卡密

## 10. 已知问题与待办

- 大世界登录风控：同 IP 短时间登录过多会触发“高风险”风控；已解析中文提示，等待冷却；后续可做会话缓存/限速
- 每次刷新 = 完整重新登录，无会话缓存（已记录优化方向）
- 未实现 HTTPS（纯 IP + HTTP，朋友自用可接受；正式化需域名/备案或换香港）
- 未做多设备账号同步（账号数据按卡密 + 电脑隔离，符合当前设计）
- 更新下载带宽受限（3Mbps），当前错峰更新；后续可选 Gitee 外链 / 香港 COS+CDN
- 管理端无操作审计日志；多人共用账号可同时登录但无法区分操作者

### 安全防护优化（已实施）
