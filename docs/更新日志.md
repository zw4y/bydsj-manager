    - 替换重试窗口延长到 60 秒并使用原子替换（跨盘自动降级复制）；
    - 替换前校验新版本是有效 PE 可执行文件，防止替换成损坏/被拦截的文件；

    - 无论成败都会重新拉起目标 exe（失败时拉起旧版，应用不再“消失”）；
    - 每次更新写入结果日志 `%APPDATA%\BydsjManager\updates\update_result.log`，失败时附带原因并检测 Windows 受控文件夹访问/目标目录可写性；
    - 日志区新增“打开更新目录”按钮（直达 `%APPDATA%\BydsjManager\updates\`，可手动覆盖更新包/查看结果日志）；下次启动若检测到 24 小时内更新失败，弹窗给出手动方案（移出桌面目录、把 updater.exe 加入允许列表、手动覆盖更新包），成功则记录“上次热更新已成功应用”；
    - 根因说明：朋友端 exe 放在桌面等受控文件夹、或旧进程未及时退出时，Windows 会拒绝覆盖正在运行/受保护的文件，旧版 updater 静默失败且不重启应用，导致反复提示（含 11 个 updater 单元测试）

## 发布流程速查

1. 更新本文件：登记版本号与更新内容；
2. 修改 `app.py` 的 `APP_VERSION`；
3. 运行 `packaging/build.py` 重新打包；
4. 管理端“发布版本”上传新 exe；
5. 朋友端检查更新/自动更新验证。
