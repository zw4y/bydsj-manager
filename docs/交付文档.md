# 捕鱼大世界多账户管理软件 · 交付文档

> 版本：1.0.0 ｜ 更新日期：2026-08-13 ｜ 交付状态：开发完成、服务器已上线、exe 已封装、热更新已实现

## 1. 项目概述

本项目是一套“Windows 桌面软件 + 云服务器授权管理”的完整系统，用于朋友间自用管理捕鱼大世界游戏账号，实现：

- 不手动打开模拟器/游戏客户端即可登录账号、查询背包与仓库资源；
- 多账号统一管理、批量刷新、批量改密、仓库存取；
- 卡密授权防外传：每个使用者凭卡密进入，卡密绑定电脑；
- 用户端软件自动热更新，不用手动换 exe。

系统由三部分组成：

| 部分 | 产物 | 作用 |
|---|---|---|
| 用户端 | `dist/BydsjApp.exe` | 卡密激活 + 多账号资源管理 |
| 管理端 | `dist/BydsjAdmin.exe` | 卡密管理 + 发布新版本 |
| 卡密服务器 | Docker 容器 `card-server` | 卡密校验、机器绑定、管理员鉴权、版本分发 |

## 2. 系统架构

```text
┌─────────────────┐         ┌──────────────────────────────┐
│  用户端 BydsjApp.exe │  HTTP  │  卡密服务器（阿里云）            │
│  - 卡密激活         │ ─────▶ │  - /api/client/activate      │
│  - 账号管理/查询     │        │  - /api/client/version      │
│  - 批量刷新/改密     │        │  - /data/cards.db           │
│  - 仓库存取         │        │  - /data/releases（热更新）    │
│  - 代理/热更新       │        └──────────────────────────────┘
└────────┬────────────┘
         │ 游戏协议直连（可选代理）
         ▼
┌──────────────────────────────┐   ┌──────────────────────────┐
│ 游戏服务器（大世界/通行证）      │   │  管理端 BydsjAdmin.exe     │
│ 登录/背包/仓库/存取            │   │  卡密管理 + 发布版本        │
└──────────────────────────────┘   └───────────┬──────────────┘
                                                │ HTTP（管理员 JWT）
                                                ▼
                                    卡密服务器（同一台）
```

关键说明：

- 游戏流量不经过卡密服务器；卡密服务器只负责“授权”和“版本分发”。
- 账号密码只存用户本机；服务器不知道游戏账号密码。
- 卡密服务器不可用时，用户端无法激活，软件无法使用（这是防外传的设计前提）。

## 3. 功能清单

### 3.1 用户端

| 功能 | 说明 |
|---|---|
| 卡密激活 | 输入卡密 → 服务器校验 → 绑定本机机器码；同机放行、他机拒绝、到期/停用拒绝 |
| 账号表管理 | 10 列（序号/勾选/账号/密码/二级密码/手机号/设备码/昵称/炮台/充值）；双击编辑即保存 |
| Excel 式操作 | 右键插入/删除行、Ctrl+C 复制、Ctrl+V 批量粘贴（1-5 列）、空白行保留、行序持久化 |
| 登录/刷新 | 右键游戏账号列“登录/刷新”，自动选择大世界或通行证登录方式 |
| 资源查询 | 背包/仓库双网格切换（16 项图标），金币“亿”显示，炮台/充值自动抓取 |
| 仓库存取 | 右键图标存入/取出；弹头上限 999；二级密码 + 首次信任设备短信验证 |
| 批量刷新 | 勾选多个账号自动排队，随机延迟（默认 5-15 秒），代理自动轮换，可停止 |
| 批量改密 | 随机规则（字母/数字位数）或指定密码；成功一个自动取消一个勾选 |
| 动态代理 | 启用开关 + 抖大代理 API；每 IP 最多 8 账号；txt/json 兼容；测试代理按钮 |
| 日志 | 界面日志 + 本地 `%APPDATA%\BydsjManager\logs\operation.log` + 打开日志目录 |
| 热更新 | 启动自动检查 + “检查更新”按钮；下载进度、SHA-256 校验、updater 替换重启 |
| 界面主题 | 原生 PySide6 浅色 Fluent 风格，无第三方 UI 库 |

### 3.2 管理端

| 功能 | 说明 |
|---|---|
| 管理员登录 | 服务器地址内置，输入账号密码，JWT 鉴权 |
| 卡密管理 | 列表、批量生成（一月卡/季卡/半年卡/年卡）、CSV 导出、停用/启用、解绑机器码 |
| 发布版本 | 填版本号/更新说明，选择用户端 exe 上传，服务器生成版本清单 |

### 3.3 卡密服务器

| 接口 | 说明 |
|---|---|
| `POST /api/admin/login` | 管理员登录，返回 JWT |
| `GET /api/admin/keys` | 卡密列表 |
| `POST /api/admin/keys/generate` | 批量生成卡密 |
| `GET /api/admin/keys/export` | 导出 CSV |
| `PATCH /api/admin/keys/{id}/status` | 停用/启用 |
| `POST /api/admin/keys/{id}/unbind` | 解绑机器码 |
| `POST /api/admin/release` | 上传用户端新版本（需管理员） |
| `POST /api/client/activate` / `validate` | 客户端激活/校验 |
| `GET /api/client/version` | 最新版本清单（无发布返回 404） |
| `/releases/app_<版本>.exe` | 更新包静态下载 |

## 4. 技术栈

| 层 | 技术 |
|---|---|
| 客户端 | Python 3.12 + PySide6（Qt6），QThread/Signal 异步 |
| 服务器 | FastAPI + Uvicorn + SQLite + python-multipart |
| 数据库 | SQLite（用户端本地 + 服务器各一份） |
| 加密 | AES-GCM（本地账号密码）、PBKDF2（管理员密码）、JWT（管理令牌） |
| 网络 | httpx、urllib；游戏协议自研客户端（bydsj_client / gaia_login） |
| 代理 | 抖大代理动态 API |
| 打包 | PyInstaller 单文件 exe |
| 部署 | Docker（服务器），数据卷持久化 |

## 5. 数据存储与安全

### 5.1 用户端本机

| 内容 | 路径 | 说明 |
|---|---|---|
| 账号库 | `%APPDATA%\BydsjManager\<卡密哈希>\accounts.db` | SQLite；密码 AES-GCM 加密；按卡密隔离 |
| 代理配置 | `%APPDATA%\BydsjManager\proxy_config.json` | JSON |
| 日志 | `%APPDATA%\BydsjManager\logs\operation.log` | 文本追加 |
| 设备码缓存 | `%APPDATA%\BydsjManager\device_code.txt` | 文本 |
| 更新包 | `%APPDATA%\BydsjManager\updates\` | 下载的新 exe / updater |

### 5.2 服务器

| 内容 | 路径 | 说明 |
|---|---|---|
| 卡密/管理员库 | 容器 `/data/cards.db`（Docker 卷 `card-data`） | `admin_users`（密码哈希）、`card_keys`（卡密等） |
| 热更新文件 | 容器 `/data/releases/` | `app_<版本>.exe` + `version.json` |

安全要点：

- 服务器卡密表按需求保存明文卡密（管理端展示用），**数据库严禁外传**；
- 管理员密码只存 PBKDF2 哈希；JWT_SECRET 只在容器环境变量；
- 用户端本地密码加密存储，密钥由“卡密 + 机器码 + 盐”派生；
- 当前通信为 HTTP 明文（朋友自用）；正式化建议后续上 HTTPS。

## 7. 服务器部署手册

### 7.1 当前环境

- 阿里云 ECS（国内），Ubuntu 22.04，2 核 2G，40G 盘
- 公网地址：`http://47.100.188.139:18432`
- 服务：Docker 容器 `card-server`（`restart always`），镜像 `card-server:latest`
- 数据卷：`card-data:/data`（数据库 + 发布目录都在这）
- 安全组：仅放行 22、18432；80/443 关闭
- 备案情况：未备案，纯 IP + 非标准端口方案（朋友自用）

### 7.2 管理员凭据

- 账号：`admin`
- 密码与 JWT 密钥：保存在 `%TEMP%\bydsj_deploy_admin_credentials.txt`
- 注意：`%TEMP%` 可能被系统清理，请尽快转存到安全位置

### 7.3 日常运维命令

```bash
ssh root@47.100.188.139
docker ps                                   # 服务状态
docker logs --tail 50 card-server           # 最近日志
docker restart card-server                  # 重启服务
docker exec card-server ls /data/releases   # 查看发布文件
```

### 7.4 备份

```bash
docker exec card-server tar czf /tmp/cards-backup.tar.gz /data
docker cp card-server:/tmp/cards-backup.tar.gz /root/cards-backup.tar.gz
```

建议每周/每次发版前备份。

### 7.5 管理员密码重置（忘记密码同样适用）

1. 先备份数据卷；
2. 删除 admin 记录：`docker exec card-server python -c "import sqlite3; c=sqlite3.connect('/data/cards.db'); c.execute(\"DELETE FROM admin_users WHERE username='admin'\"); c.commit()"`；
3. 用新 `CARD_ADMIN_PASSWORD` 重建容器（保留同一数据卷与 `CARD_JWT_SECRET`）；
4. 验证新密码登录。

> 只删 admin 不会丢卡密；卡密表与 admin 表相互独立。

### 7.6 重新部署/升级服务器

```bash
cd /opt/card-server
docker build -f server/Dockerfile -t card-server .
docker rm -f card-server
docker run -d --name card-server --restart always \
  -p 18432:8000 -v card-data:/data \
  -e CARD_DB_PATH=/data/cards.db \
  -e CARD_ADMIN_PASSWORD=<管理员密码> \
  -e CARD_JWT_SECRET=<JWT密钥> \
  card-server
```

## 8. 客户端封装与热更新

### 8.1 打包产物

| 文件 | 大小 | 说明 |
|---|---|---|
| `dist/BydsjApp.exe` | ~63MB | 用户端，自定义图标 |
| `dist/BydsjAdmin.exe` | ~51MB | 管理端，默认图标 |
| `dist/updater.exe` | ~8MB | 内嵌在用户端，不单独分发 |

### 8.2 打包方法

```powershell
.\.venv\Scripts\python.exe packaging\build.py
```

打包前请关闭正在运行的 BydsjApp/BydsjAdmin 进程，否则 exe 被占用会失败。

### 8.3 排除清单

打包只包含：运行代码、协议模板、道具图标、依赖、updater。
严格排除：`dumps/`、`tools/`、`tests/`、`docs/`、`packaging/`、`server/`、`.venv/`、数据库、日志、凭据等（详见 `docs/打包清单与逆向资产说明.md`）。

### 8.4 版本与发布

- 当前版本：`1.0.0`（`app.py` 的 `APP_VERSION`）
- 发布流程：
  1. 修改代码 → 递增 `APP_VERSION` → 重新打包；
  2. 打开 `BydsjAdmin.exe` → “发布版本” → 填版本号/说明 → 选择新 exe → 上传；
  3. 用户端启动或点“检查更新”会自动发现、下载、校验、替换重启。
- 更新失败/校验失败：保留旧版，不影响使用。
- 带宽：服务器 3Mbps，单个 63MB 下载约 3 分钟；建议错峰更新。后续可接 Gitee 外链或香港 COS+CDN。

## 9. 使用指南

### 9.1 用户端

1. 双击 `BydsjApp.exe`；
2. 输入管理端生成的有效卡密 → 激活进入；
3. 空白区域右击 → “添加行/粘贴账号数据”导入账号（建议包含设备码）；
4. 勾选账号 → 手动刷新；或“批量刷新”；
5. 资源面板切换“背包道具/仓库道具”，右键图标存取；
6. 代理按需开启；日志区可打开日志目录、检查更新。

### 9.2 管理端

1. 双击 `BydsjAdmin.exe`；
2. 输入 `admin` 与管理员密码登录；
3. 生成卡密 → 把卡密发给朋友；
4. 朋友换电脑 → 解绑机器码；
5. 发新版 → “发布版本”上传。

## 11. 已知限制与后续路线

| 事项 | 状态 | 说明 |
|---|---|---|
| HTTPS | 未做 | 纯 IP + HTTP；正式化需域名/备案或香港服务器 |

| 管理审计 | 未做 | 多人共用管理端时无操作留痕 |
